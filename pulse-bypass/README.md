# Pulse Bypass

Desktop-приложение (Electron, Windows) для обхода DPI-блокировок YouTube,
Discord и других сервисов. Движком обхода служит [zapret](https://github.com/bol-van/zapret)
(`winws.exe` + драйвер [WinDivert](https://reqrypt.org/windivert.html)) —
Pulse Bypass не переизобретает низкоуровневую часть, а даёт удобный GUI
поверх официального движка: автоподбор рабочей стратегии, включение/выключение
сайтов и доменов одним кликом, добавление своих сайтов и трей-иконку.

Как это работает: WinDivert перехватывает исходящий TCP/UDP-трафик вашего
собственного устройства и слегка видоизменяет пакеты (разбивка TLS
ClientHello, фейковые пакеты, автоподбор TTL и т.п.), из-за чего DPI-система
провайдера не может по открытому SNI понять, к какому домену идёт
соединение, и не блокирует/не режет его. Содержимое трафика не подделывается.

## Возможности

- Включение/выключение обхода одной кнопкой, статус в трее и в титлбаре.
- Автоподбор стратегии: приложение по очереди пробует несколько стратегий
  из `engine/strategies.js` и проверяет TLS-соединение к YouTube/Discord,
  оставляя включённой первую рабочую.
- Отдельные списки доменов для YouTube, Discord и общего списка (Instagram,
  Facebook, X, Telegram, WhatsApp) — включаются чекбоксами.
- Добавление своих сайтов (`engine/hostlists`, дополняется пользовательским
  списком, который живёт в `%AppData%/pulse-bypass`).
- Добавление «приложений» как меток к вашим доменам обхода — **важно**:
  `winws.exe` фильтрует трафик по домену/порту глобально, а не по конкретному
  `.exe`-процессу, поэтому это не пер-процессная фильтрация, а способ
  организовать список для себя.
- Автозапуск обхода при старте программы и автозапуск программы при
  включении компьютера.
- Дизайн в стиле Pulse-hub (тёмный терминальный зелёный, Space Grotesk +
  IBM Plex Mono, собственный титлбар).

## Структура проекта

```
main.js                 — главный процесс Electron, IPC, трей
preload.js               — contextBridge: window.desktop / window.pulse
engine/
  strategies.js           — пресеты аргументов winws.exe
  zapret-manager.js        — запуск/остановка движка, автоподбор
  vendor-fetch.js           — загрузка официального бинарного бандла zapret
  hostlists/*.txt            — встроенные списки доменов
src/
  index.html, assets/*         — интерфейс (дизайн Pulse-hub)
scripts/download-zapret.js       — предзагрузка движка перед сборкой (CI)
.github/workflows/build.yml       — сборка Windows-инсталлятора
```

## Разработка

```bash
npm install
npm start            # запуск в dev-режиме (Windows; на другой ОС часть функций движка недоступна)
```

## Сборка инсталлятора

Сборка автоматическая — через GitHub Actions (`.github/workflows/build.yml`):
пуш тега `v*` или ручной запуск workflow собирает `.exe` на `windows-latest`
и прикладывает его к GitHub Release. Локально на Windows:

```bash
npm install
npm run fetch-engine   # скачивает winws.exe + WinDivert с bol-van/zapret-win-bundle
npm run dist            # electron-builder → dist/Pulse Bypass Setup *.exe
```

Если `fetch-engine` не запускался (например, вы просто нажали «Пуск» из
исходников), приложение попробует скачать движок само при первом запуске
обхода — кнопка «переустановить движок» в меню (☰) делает то же самое вручную.

## Права администратора

WinDivert — kernel-mode драйвер, поэтому `winws.exe` требует запуска от
администратора. Установщик (`requestedExecutionLevel: requireAdministrator`
в `package.json`) запрашивает повышение прав автоматически.

## Важно

- Zapret и WinDivert — сторонние open-source проекты со своими лицензиями
  (zapret — GPL-3.0, WinDivert — LGPL-3.0/GPL-2.0). Pulse Bypass лишь
  скачивает официальные бинарники с их GitHub Releases и запускает их —
  сам код этих проектов в данный репозиторий не копируется.
- Стратегии обхода (`engine/strategies.js`) могут переставать работать
  при обновлении оборудования DPI на стороне провайдера — тогда помогает
  кнопка «автоподбор» либо добавление новой стратегии вручную.
- Легальность использования средств обхода блокировок зависит от вашей
  юрисдикции — уточняйте местное законодательство самостоятельно.
