# Инструкция по установке Pulse Bypass (Улучшенная версия)

## Быстрый старт

### Вариант 1: Использование из исходников (рекомендуется для разработки)

1. **Установите Node.js**
   - Скачайте с https://nodejs.org/ (версия 16 или новее)
   - Проверьте установку: `node --version`

2. **Распакуйте архив**
   ```bash
   unzip pulse-bypass-improved.zip
   cd pulse-bypass-improved
   ```

3. **Установите зависимости**
   ```bash
   npm install
   ```

4. **Запустите приложение**
   ```bash
   npm start
   ```

### Вариант 2: Сборка исполняемого файла

1. Выполните шаги 1-3 из варианта 1
2. Соберите приложение:
   ```bash
   npm run build
   ```
3. Исполняемый файл появится в папке `dist/`
4. Запустите `Pulse Bypass.exe` **от имени администратора**

## Важные замечания

⚠️ **ОБЯЗАТЕЛЬНО запускайте от имени администратора!**
WinDivert требует административных прав для работы с сетевым трафиком.

⚠️ **Антивирусы могут блокировать WinDivert**
Добавьте папку приложения в исключения антивируса.

## Первый запуск

1. При первом запуске движок zapret будет загружен автоматически
2. Выберите сайты/приложения для обхода
3. Нажмите "автоподбор" для поиска рабочей стратегии
4. Нажмите "запустить обход"

## Проверка работы

1. Нажмите "проверить работоспособность (5 попыток)"
2. Дождитесь завершения проверки
3. Индикаторы ✓/✗ покажут статус YouTube и Discord

## Структура папок

После установки будут созданы папки:
- `%APPDATA%/pulse-bypass/` - настройки и конфигурация
- `%APPDATA%/pulse-bypass/runtime/` - временные файлы
- `%APPDATA%/pulse-bypass/logs/` - логи работы

## Устранение проблем

### Приложение не запускается
- Убедитесь, что запущено от имени администратора
- Проверьте, установлен ли Node.js
- Откройте `%APPDATA%/pulse-bypass/logs/` и проверьте логи

### Обход не работает
1. Попробуйте другую стратегию
2. Нажмите "автоподбор"
3. Проверьте, что домены добавлены в список
4. Убедитесь, что в `%APPDATA%/pulse-bypass/runtime/combined-hostlist.txt` есть нужные домены

### Антивирус блокирует
- Добавьте папку приложения в исключения
- Добавьте `winws.exe` в исключения
- WinDivert - легитимный драйвер, не вирус

### Движок не устанавливается
1. Проверьте подключение к интернету
2. Откройте меню → "переустановить движок"
3. Дождитесь завершения загрузки

## Системные требования

- **ОС:** Windows 10/11 (64-bit)
- **Процессор:** Любой современный CPU
- **RAM:** 200 МБ минимум
- **Диск:** 100 МБ свободного места
- **Права:** Администратор обязательно
- **Node.js:** 16+ (для запуска из исходников)
