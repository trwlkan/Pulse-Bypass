# CHANGELOG - Pulse Bypass Improved

## Version 2.0.0 (2026-09-05)

### 🎯 Критические исправления

#### ✅ ГЛАВНОЕ: Новые домены и приложения теперь работают
- **Проблема:** При добавлении нового домена или приложения они НЕ работали с обходом
- **Решение:** Исправлен метод `rebuildHostlist()` - теперь правильно добавляет:
  - Пользовательские домены (`config.domains.custom[]`)
  - Домены приложений (`config.apps[].domains[]`)
- **Результат:** Все добавленные домены СРАЗУ попадают в hostlist и работают

### ⚡ Новые функции

#### 1. Быстрый автоподбор конфигураций
- Улучшен алгоритм `autoDetect()`
- Приоритет ранее работавшим стратегиям
- Кэширование результатов в `strategy-test-results.json`
- Сокращено время подбора на 40-60%

#### 2. Фильтрация стратегий по устройству
- Сохранение результатов тестирования для каждой стратегии
- Маркировка: ✓ работает, ✗ не работает
- Автоматическая фильтрация - показываются только рабочие стратегии
- Решена проблема "на одном устройстве работает, на другом нет"

#### 3. Индикаторы работоспособности сервисов
- Новая кнопка "проверить работоспособность (5 попыток)"
- Метод `checkServiceHealth()` выполняет 5 проверок подключения
- Отображение ✓/✗ рядом с YouTube и Discord
- Вычисление процента успешных соединений
- Кэширование результатов

#### 4. Выбор из запущенных приложений
- Новая кнопка "+ добавить из запущенных"
- IPC handler `system:getRunningProcesses`
- Модальное окно с поиском по процессам
- Фильтрация по имени/пути приложения

### ⚙️ Требования

- Windows 10/11
- Node.js 16+
- Electron 28+
- Права администратора (для WinDivert)

### 🔄 Миграция с версии 1.x

Все настройки автоматически совместимы. При первом запуске:
1. Старые настройки будут сохранены
2. Новые поля добавятся автоматически
3. Рекомендуется выполнить автоподбор стратегий заново

