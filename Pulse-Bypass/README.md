# Pulse Bypass - Улучшенная версия

Улучшенное приложение для обхода блокировок с исправлениями основных проблем и новыми функциями.

## Что исправлено

### 1. ✅ ГЛАВНАЯ ПРОБЛЕМА: Новые сайты и приложения теперь работают
**Раньше:** При добавлении нового домена или приложения они НЕ работали с обходом, даже когда обход был включён. Работали только предустановленные YouTube, Discord и General.

**Теперь:** Исправлен метод `rebuildHostlist()` - он правильно добавляет:
- Пользовательские домены из `config.domains.custom[]`
- Домены приложений из `config.apps[].domains[]`

Все добавленные домены **сразу работают** с обходом!

### 2. ✅ Быстрый автоподбор конфигураций
- Улучшен алгоритм автоподбора стратегий
- Приоритет отдаётся ранее работавшим стратегиям
- Результаты тестирования сохраняются в `strategy-test-results.json`
- Быстрее находит рабочую стратегию

### 3. ✅ Фильтрация стратегий по устройству
- Стратегии, которые работают на вашем устройстве, помечаются ✓
- Стратегии, которые не работают, помечаются ✗
- В выпадающем списке показываются только рабочие стратегии (если есть протестированные)
- Решает проблему "на одном устройстве YouTube работает, на другом нет"

### 4. ✅ Индикаторы работоспособности сервисов
- Новая кнопка **"проверить работоспособность (5 попыток)"**
- Проверяет YouTube и Discord 5 раз каждый
- Показывает ✓ (работает) или ✗ (не работает) рядом с названием сервиса
- Определяет процент успешных подключений

### 5. ✅ Выбор из запущенных приложений
- Новая кнопка **"+ добавить из запущенных"**
- Показывает модальное окно со списком всех запущенных .exe процессов
- Поиск по имени/пути приложения
- Больше не нужно искать .exe файлы вручную!

### 6. ✅ Кнопка включить/выключить
- Уже существует и работает корректно
- Кнопка "запустить обход" / "остановить обход"

## Технические улучшения

### zapret-manager.js
```javascript
// ИСПРАВЛЕНО: rebuildHostlist теперь правильно добавляет пользовательские домены
if (config.domains && Array.isArray(config.domains.custom)) {
  config.domains.custom.forEach((entry) => {
    if (entry.enabled !== false && entry.host) {
      add(entry.host);
    }
  });
}

// ИСПРАВЛЕНО: добавляем домены из приложений
if (Array.isArray(config.apps)) {
  config.apps.forEach((app) => {
    if (app.enabled !== false && Array.isArray(app.domains)) {
      app.domains.forEach(add);
    }
  });
}
```

### Новые методы
- `checkServiceHealth(serviceName, host, port, attempts)` - проверка с 5 попытками
- `_loadStrategyResults()` / `_saveStrategyResults()` - кэширование результатов
- `getWorkingStrategies()` - получение только рабочих стратегий

### Новые IPC хендлеры (main.js)
- `engine:checkServiceHealth` - проверка работоспособности сервисов
- `system:getRunningProcesses` - получение списка запущенных процессов
- `config:addApp` улучшен для поддержки добавления из запущенных

### UI улучшения (app.js)
- `renderServiceHealth()` - отображение индикаторов ✓/✗
- `createProcessSelectorModal()` - модальное окно выбора процессов
- `renderStrategies()` - фильтрация и маркировка стратегий

## Использование

### Добавление домена
1. Введите домен (например, `example.com`) в поле "добавить сайт"
2. Нажмите "добавить"
3. Домен сразу добавится в hostlist и будет работать с обходом

### Добавление приложения
**Способ 1:** Через файл
- Нажмите "+ добавить приложение (.exe)"
- Выберите .exe файл

**Способ 2:** Из запущенных (НОВОЕ!)
- Нажмите "+ добавить из запущенных"
- Найдите нужное приложение в списке
- Кликните на него

### Автоподбор стратегии
1. Нажмите кнопку "автоподбор"
2. Дождитесь завершения (программа протестирует все стратегии)
3. Рабочая стратегия будет автоматически выбрана и сохранена

### Проверка работоспособности
1. Нажмите "проверить работоспособность (5 попыток)"
2. Программа выполнит 5 проверок для YouTube и Discord
3. Рядом с названиями появятся индикаторы:
   - ✓ (зелёный) = работает
   - ✗ (красный) = не работает

### Как работает исправление hostlist
Раньше:
```javascript
// Собирались только предустановленные списки
youtube.txt → hostlist

general.txt → hostlist
// custom домены ИГНОРИРОВАЛИСЬ ❌
```

Теперь:
```javascript
// Собираются ВСЕ домены

config.domains.custom[] → hostlist ✅
config.apps[].domains[] → hostlist ✅
```

```javascript
// После каждого автоподбора сохраняется:

    "timestamp": 1725544850000
```

## Требования

- Windows 10/11
- Node.js 16+
- Права администратора (для WinDivert)

## Известные ограничения

1. **Платформа:** Работает только на Windows (WinDivert - Windows-only)
2. **Права:** Требуется запуск от имени администратора
3. **Фильтрация:** winws.exe фильтрует по домену/порту глобально, а НЕ по конкретному .exe процессу
4. **WinDivert:** При аварийном закрытии приложения процесс winws.exe может остаться в фоне

## Устранение проблем

### Движок не запускается
1. Запустите от имени администратора
2. Проверьте антивирус (может блокировать WinDivert)
3. Нажмите "переустановить движок" в меню

### Домены не работают
1. Проверьте `%APPDATA%/pulse-bypass/runtime/combined-hostlist.txt`
2. Ваши домены должны быть в этом файле
3. Если их там нет - сообщите об ошибке

### Стратегия не работает
1. Нажмите "автоподбор"
2. Дождитесь завершения
3. Используйте найденную рабочую стратегию
